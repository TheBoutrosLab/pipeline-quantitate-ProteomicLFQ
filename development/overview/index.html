Overview

This pipeline takes the mass spectrometry data from label free data dependent acquisition (DDA) proteomic studies, map them with the library search results, and quantitate peptide abundance. The mass spectrometry data must be in the mzML format, and can be converted from raw files using ucla-cds/pipeline-convert-MSData. The library search result must be in idXML file, which can be generated using the ucla-cds/pipeline-search-ProteomicMSMS and ucla-cds/pipeline-validate-ProteomicPSM. The outputted consensusXML can be used downstream for protein inference and quantitation.

In this pipeline we implemented the targeted feature detection algorithm published by Weisser et al in 2017. For each mzML file, the features were first extracted using FFId (FeatureFinderIdentification) with the identification results. The features are then aligned across all samples at the study/cohort level. The retention times are then transformed, and then samples are merged to into consensus features. FFId provides three strategies, as internal-only, int/ext-merged, and machine-learning. For internal-only, only peptide identification results from the corresponding mzML is used. For int/ext-merged, all idXMLs from the same cohort/experiment are first aligned then merged and used to find features. The machine-learning strategy first align all idXMLs but treat internal and external identifications separately. Read the FFId paper for more detail.
